# Datos pendientes: quantum-blueprint

El código funciona; donde falte un dato lanza `PENDIENTE: falta dato X`. Rellena `datos_pendientes.yaml` (campo `valor`).

| clave | descripción | unidades | estado |
|---|---|---|---|
| `material_o_atomo` | sistema cuántico concreto del plan (átomo, ion o defecto) | texto | PENDIENTE |
| `campo_b_t` | campo magnético de trabajo | T | PENDIENTE |
| `desdoblamiento_hiperfino_hz` | desdoblamiento hiperfino a campo cero | Hz | PENDIENTE |
| `espin_nuclear_i` | espín nuclear I | adimensional | PENDIENTE |
