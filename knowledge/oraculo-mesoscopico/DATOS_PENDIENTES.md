# Datos pendientes: oraculo-mesoscopico

El código funciona; donde falte un dato lanza `PENDIENTE: falta dato X`. Rellena `datos_pendientes.yaml` (campo `valor`).

| clave | descripción | unidades | estado |
|---|---|---|---|
| `sistema` | dispositivo mesoscópico a predecir | texto | PENDIENTE |
| `transmisiones_media` | transmisión media de cada canal | lista [0-1] | PENDIENTE |
| `transmisiones_sigma` | incertidumbre de cada transmisión | lista | PENDIENTE |
