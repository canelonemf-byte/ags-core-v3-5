# Datos pendientes: neuroglyq

El código funciona; donde falte un dato lanza `PENDIENTE: falta dato X`. Rellena `datos_pendientes.yaml` (campo `valor`).

| clave | descripción | unidades | estado |
|---|---|---|---|
| `variable_principal` | variable de resultado primaria del ensayo | texto | PENDIENTE |
| `diferencia_clinica_relevante` | diferencia mínima clínicamente relevante | unidades de la variable | PENDIENTE |
| `desviacion_estandar` | desviación estándar de la variable (de estudios previos) | unidades de la variable | PENDIENTE |
| `alfa` | error tipo I bilateral | probabilidad | PENDIENTE (ejemplo público: 0.05, convención, Noordzij 2010) |
| `potencia` | 1 - error tipo II | probabilidad | PENDIENTE (ejemplo público: 0.8, convención, Noordzij 2010) |
| `abandono` | fracción de abandono esperada | fracción | PENDIENTE |
| `datos_preclinicos` | datos in vitro/in vivo que justifiquen pasar a ensayo | tabla | PENDIENTE |
